Track Types

Seven tracks, one package

From signal coverage to Hi-C contact matrices, ezGenomeTracks covers the full spectrum of genomic visualization needs.

Coverage

ChIP-seq, ATAC-seq, RNA-seq signal tracks from bigWig files or data frames.

ez_coverage()

Gene

Gene models with exons, introns, and UTRs from TxDb objects or GTF files.

ez_gene()

Feature / Peak

Genomic intervals — peaks, enhancers, promoters — from BED files or data frames.

ez_feature()

Link / Arc

Chromatin loops, enhancer-promoter interactions, and genomic arcs.

ez_link()

Sashimi

RNA-seq splice junction plots with coverage and arc-based junction display.

ez_sashimi()

Manhattan

GWAS association plots — genome-wide or regional LocusZoom-style views.

ez_manhattan()

Hi-C

Contact matrices, TADs, and 3D chromatin structure visualization.

ez_hic()
Simple by Design

From file to plot in one line

ezGenomeTracks handles data import, coordinate parsing, theming, and scaling automatically. Stack multiple tracks with a shared genomic axis using vstack_plot().

  • Flexible input: file paths, data frames, GRanges, or named lists
  • Automatic genomic coordinate formatting (kb/Mb)
  • Clean publication-ready themes out of the box
  • Full ggplot2 compatibility — add any layer or scale
  • Multi-sample support via faceted or overlapping tracks
example.R 
library(ezGenomeTracks)

# Define a genomic region
region <- "chr2:231109000-231115000"

# Create individual tracks
cov <- ez_coverage(
  bw_file, region,
  colors = "steelblue"
)

genes <- ez_gene(txdb, region)

# Stack with shared x-axis
vstack_plot(
  cov, genes,
  region = region,
  heights = c(2, 1)
)

Why ezGenomeTracks

Built for the ggplot2 ecosystem

A different approach to genome browser tracks — modular, composable, and fully customizable.

ggplot2 Native

Every track is a ggplot object. Add layers, scales, themes, and annotations using the full ggplot2 grammar of graphics.

Easy Wrappers

One-line track creation with ez_*() functions that auto-detect input types, parse regions, and apply sensible defaults.

Stackable

Compose complex multi-track figures with vstack_plot() and hstack_plot() — shared axes, controlled heights, aligned coordinates.
