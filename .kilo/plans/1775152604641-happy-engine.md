# ezGenomeTracks Landing Page Plan

## Overview

Create a single-file landing page (`ezGT_landing/index.html`) for the ezGenomeTracks R package with a modern, vibrant design inspired by genomic data visualization aesthetics.

## Design Direction

### Theme: "Dark Genome Browser"

A dark-mode aesthetic inspired by genome browsers at night — deep backgrounds with bright, data-driven accent colors that mirror the vivid signals seen in genomic tracks.

### Color Palette

```css
--bg-primary: #0a0e17;      /* Deep navy-black */
--bg-secondary: #111827;    /* Slightly lighter navy */
--bg-card: #1a2235;         /* Card background */
--accent-teal: #00e5c7;     /* Bright teal - primary accent */
--accent-coral: #ff6b6b;    /* Coral - secondary accent */
--accent-amber: #ffc857;    /* Warm amber - tertiary */
--accent-blue: #4dabf7;     /* Soft blue */
--accent-purple: #b197fc;   /* Light purple for variety */
--text-primary: #f8f9fa;    /* Near-white text */
--text-secondary: #a0aec0;  /* Muted text */
--text-code: #79c0ff;       /* Code syntax highlight blue */
```

### Typography

- **Headings**: `Sora` (Google Fonts) — geometric, warm, distinctive
- **Body**: `Atkinson Hyperlegible` (Google Fonts) — highly readable, designed for accessibility
- **Code**: `JetBrains Mono` (Google Fonts) — clean, developer-focused monospace

### Background Treatment

- Layered radial gradients creating subtle depth
- Faint grid pattern overlay (CSS-generated, inspired by genomic coordinate grids)
- Subtle animated gradient shift on hero section

## Page Structure

### 1. Hero Section (Full viewport height)

- **Package name**: "ezGenomeTracks" — large, bold, with gradient text effect
- **Tagline**: "Minimal, ggplot2-based genome browser tracks for R"
- **Two CTA buttons**:
  - Primary: "View Documentation" → placeholder URL `#docs` (user will update)
  - Secondary: "GitHub" → `https://github.com/Zepeng-Mu/ezGenomeTracks`
- **Quick install snippet**: `devtools::install_github("Zepeng-Mu/ezGenomeTracks")`
- **Animations**: Staggered fade-up on page load (animation-delay cascade)

### 2. Track Types Grid

- 7 cards in a responsive grid (3-4 columns on desktop, 2 on tablet, 1 on mobile)
- Each card: icon (CSS-generated geometric shapes), track name, one-line description
- Cards: Coverage, Gene, Feature, Link, Sashimi, Manhattan, Hi-C
- Hover: subtle lift + accent border glow

### 3. Code Example Section

- Split layout: code block on left, description on right (stacked on mobile)
- Shows the core workflow: `ez_coverage()` → `vstack_plot()`
- Syntax-highlighted code with custom styling
- Background: subtle code-pattern texture

### 4. Image Carousel

- Auto-playing carousel with 4 slots for example figures
- Placeholder images from `man/figures/` (user can update later)
- Smooth CSS transitions between slides
- Navigation dots + prev/next arrows
- Images: `index-example-quick-1.png`, `index-example-multi-1.png`, and 2 more from the package

### 5. Why ezGenomeTracks?

- 3-column feature highlights:
  - **ggplot2 Native**: Full compatibility with ggplot2 ecosystem
  - **Easy Wrappers**: One-line track creation with `ez_*()` functions
  - **Stackable**: Vertical/horizontal composition with shared axes
- Each with a distinctive icon and brief description

### 6. Footer

- Minimal footer with GitHub link, documentation link, license info
- "Built with ggplot2" badge

## Animations & Interactions

### Page Load Sequence (CSS-only)
1. Hero content fades up with staggered delays (0ms, 150ms, 300ms, 450ms)
2. Track cards cascade in from bottom (staggered 80ms apart)
3. Code section slides in from left
4. Carousel fades in

### Micro-interactions (CSS-only)
- Card hover: `transform: translateY(-4px)` + box-shadow accent glow
- Button hover: background color shift + slight scale
- Carousel: smooth crossfade transitions
- Code block: subtle highlight on hover

## Technical Implementation

### Single HTML File Structure
```
ezGT_landing/
└── index.html
    ├── <head> with Google Fonts imports
    ├── <style> — all CSS inline
    ├── <body>
    │   ├── Hero section
    │   ├── Track types grid
    │   ├── Code example
    │   ├── Image carousel
    │   ├── Features section
    │   └── Footer
    └── <script> — minimal JS for carousel only
```

### Responsive Breakpoints
- Desktop: > 1024px
- Tablet: 768px - 1024px
- Mobile: < 768px

### Carousel Images (placeholders)
The carousel will reference these images (copy from package to `ezGT_landing/assets/`):
1. `man/figures/index-example-quick-1.png` — Single coverage track
2. `man/figures/index-example-multi-1.png` — Multi-sample stacked coverage
3. `figure/gwas-1.png` — Manhattan plot
4. `figure/hic-signal-1.png` — Hi-C triangle view

**Note**: User can update/replace these images later. Image paths in HTML will be easy to modify.
